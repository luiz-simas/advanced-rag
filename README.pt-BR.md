# Advanced RAG System

Projeto RAG local integrado ao Ollama/Llama 3 e banco vetorial.

## Instruções de Uso
1. Instale as dependências: `pip install -r requirements.txt`
2. Coloque seus PDFs na pasta `data/documents/`
3. Execute o script de ingestão: `python ingest.py`
4. Inicie a interface: `streamlit run app.py`
